Definition 4.1.1.

Given a square \(n\times n\) matrix \(A\text{,}\) we say that a nonzero vector \(\vec{v}\) is an eigenvector of \(A\) if there is a scalar \(\lambda\) such that
\begin{equation*} A\vec{v} = \lambda \vec{v}\text{.} \end{equation*}
The scalar \(\lambda\) is called the eigenvalue associated to the eigenvector \(\vec{v}\text{.}\)
