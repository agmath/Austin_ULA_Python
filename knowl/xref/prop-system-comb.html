Proposition 2.1.12.

The vector \(\vec{b}\) is a linear combination of the vectors \(\vec{v_1},\vec{v_2},\ldots,\vec{v_n}\) if and only if the linear system corresponding to the augmented matrix
\begin{equation*} \left[ \begin{array}{rrrr|r} \vec{v_1} \amp \vec{v_2} \amp \ldots \amp \vec{v_n} \amp \vec{b} \end{array} \right] \end{equation*}
is consistent. A solution to this linear system gives weights \(c_1,c_2,\ldots,c_n\) such that
\begin{equation*} c_1\vec{v_1} + c_2\vec{v_2} + \ldots + c_n\vec{v_n} = \vec{b}\text{.} \end{equation*}
