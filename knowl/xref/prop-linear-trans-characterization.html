Proposition 2.6.3.

The function \(T:\real^n\to\real^m\) is a matrix transformation where \(T(\vec{x}) = A\vec{x}\) for some \(m\times n\) matrix \(A\) if and only if
\begin{equation*} \begin{aligned} T(c\vec{v}) \amp {}={} cT(\vec{v}) \\ T(\vec{v} + \vec{w}) \amp {}={} T(\vec{v}) + T(\vec{w})\text{.} \end{aligned}\text{.} \end{equation*}
In this case, \(A\) is the matrix whose columns are \(T(\vec{e_j})\text{;}\) that is,
\begin{equation*} A=\left[\begin{array}{rrrr} T(\vec{e_1}) \amp T(\vec{e_2}) \amp \ldots \amp T(\vec{e_n}) \end{array}\right]\text{.} \end{equation*}
