Proposition 2.5.6.

If \(T:\real^n\to\real^m\) is a matrix transformation given by \(T(\vec{x}) = A\vec{x}\text{,}\) then the matrix \(A\) has columns \(T(\vec{e_j})\text{;}\) that is,
\begin{equation*} A = \left[\begin{array}{rrrr} T(\vec{e_1}) \amp T(\vec{e_2}) \amp \cdots \amp T(\vec{e_n}) \end{array}\right]\text{.} \end{equation*}
